## 2. 커리큘럼 구조

수업 교재 **『바로 배워 바로 쓰는 세종학당 한국어 입문』**의 목차와 교수 흐름을 따릅니다. 목차·순서만 맞추고, 예시 단어·설명·대화·문항은 모두 새로 작성했습니다.

| 단원 | 레슨 (교재 과) | 핵심 내용 |
|---|---|---|
| 예비편 | L00 한국어와 한글 | 한복·한식·한옥, 한글 창제 역사, 제자 원리(천지인·발음 기관) |
| 기본 모음과 자음 | L01 기본 모음 · L02 기본 자음 · R1 연습 활용(1) | ㅏㅓㅗㅜㅡㅣㅔㅐ, ㄱㄴㄷㄹㅁㅂㅅㅇㅈ, ㅇ+모음 음절 |
| 격음과 경음 | L03 격음 · L04 경음 · R2 연습 활용(2) | ㅋㅌㅍㅊㅎ, ㄲㄸㅃㅆㅉ, 평음·격음·경음 비교 |
| 이중 모음 | L05 이중 모음 1 · L06 이중 모음 2 · R3 연습 활용(3) | ㅑㅕㅛㅠㅖㅒ, ㅘㅝㅙㅞㅚㅟㅢ |

| 겹받침과 연음 | L09 겹받침 · L10 연음 · R5 연습 활용(5) | ㄺ ㄼ ㅀ ㅄ ㄵ ㄶ, 기본·겹받침·ㅎ 연음 |
| 교실 표현과 인사 | L11 표현 1 · L12 표현 2 | 교실 표현(-(으)세요, 알겠어요/모르겠어요), 인사·감사·사과·식사·작별 |
| 보너스 회화 (초안) | C1–C8 | 교재 이후 생활 회화 — 교사가 공개 여부 결정 |

각 레슨의 흐름 (교재와 동일):
1. **도입** — 생활 속 한글·상황으로 동기 유발
2. **학습** — 글자별 입 모양(보리 캐릭터)·발음 팁·예시 단어 (예시 단어 그림 104px — 같은 레슨 어휘의 그림을 쓰고, 어휘에 없는 단어는 `example.emoji`)
3. **쓰기** — 칸 안의 흐린 글자를 따라 쓰기 (교재 "다음을 써 보세요")
4. **어휘 읽기** — 큰 그림·로마자·[실제 발음] 표기. 그림은 이모지를 Twemoji 그림(SVG)으로 앱에 넣어 모든 기기에서 같은 모양으로 표시(`src/components/PicIcon.tsx`, 묶음 `src/lib/emojiIcons.json` ← `node scripts/build-emoji-icons.mjs`). 맞는 이모지가 없는 한국 고유의 것(한복·한옥·한글·한식/비빔밥·김치·떡볶이·김밥·자두·감·타조·필통·원)은 자체 제작 아이콘(`src/components/icons/koreanIcons.tsx`), 뜻과 어긋난 그림은 `server/emojiFixes.js`로 교정. 평가의 「🍑 = ?」형 문제와 그림 보기도 크게 표시. 테스트(`server/tests/pictures.test.js`)가 그림 누락을 잡아냄
5. **발음 연습** — 듣고 따라 하기, 소리 비교(어/오, 가/카/까 등), 음성 인식 채점
6. **평가** — 듣고 고르기·음절 완성·그림 단어 고르기 (자동 채점)
7. **과제/문화/AI 대화** — 11·12과는 Gemini 역할극(교실·인사 상황)

연습 활용(R1–R5)은 두 과마다 복습: 듣고 단어 고르기, 빈칸 채우기, 단어 쓰기.

## 3. 주요 기능 설계

### 3.1 발음 코치 '보리' (2D 캐릭터)
- 자체 제작 SVG 호랑이 캐릭터, 기분 표정 6종(기본/기쁨/환호/생각/아쉬움/듣는 중)
- 디자인 모티프: 조선 민화 「까치호랑이」(공공 영역) — 크고 익살스러운 눈(세로를 조금 줄인 타원), 굵은 눈썹, 물결 줄무늬, 뺨의 갈기. 특정 애니메이션 캐릭터의 모양·색(파란 호랑이 등)은 따르지 않고 민화의 황토빛 주황을 사용
- 큰 입은 수치형(벌림·너비·둥글기·치아·혀·입꼬리)으로 그리고, 스프링 보간(감쇠 진동 없이)으로 모음 사이를 부드럽게 이어 줌. 말할 때는 몸이 천천히 흔들림 (`src/lib/mouthShape.ts`를 입 모양 화면과 공유)
- **입 모양(비즘) 동기화**: 음절을 자모로 분해 → 모음별 입 모양 8종(ㅏ/ㅓ/ㅗ/ㅜ/ㅡ/ㅣ/ㅐㅔ/양순음 닫힘)을 TTS 진행에 맞춰 전환, 이중모음은 2단계(ㅘ = ㅗ→ㅏ). 브라우저가 단어 경계 이벤트를 주면 재동기화
- **발음 코치 화면(학생 › 발음)의 정밀 입 모양 애니메이션** (`src/components/LipsView.tsx`): 보리 대신 사람 입을 크게 보여 줌. 앞모습(윗입술·아랫입술·윗니·아랫니·혀·입안)과 옆모습 단면(턱 벌림, 입술 내밂, 혀의 앞뒤·높낮이)을 모음별 수치(벌림·너비·둥글기·혀 위치·치아 노출)로 그리고 모음 사이를 부드럽게 보간. 퍼짐(←→)·오므림(→←)·턱 내림(↓) 화살표와 '입술/혀' 요령 태그 표시. 설명 말풍선은 그대로 위에 유지. 레슨·드라마 쉐도잉에서는 보리를 그대로 사용
- **브라우저 음성(TTS) 안정화** (`src/lib/speech.ts`): 첫 터치·클릭 때 소리 없는 발화와 무음 오디오로 음성 엔진·스피커를 미리 깨워 첫 재생 지연을 줄이고, 재생 중인 소리를 끊고 바로 다시 재생할 때 90ms 간격을 두어 앞부분이 잘리거나 찢어지는 소리를 줄임. 기본은 기기에 설치된 음성(빠른 반응)을 쓰고, 발음 화면에서 온라인 고품질 음성으로 바꿀 수 있음(두 종류가 모두 있을 때만 표시). 근본 해결은 운영 단계에서 유료 TTS로 미리 만든 음성 파일을 쓰는 것
- **자음 소리 잘림 대응**: 스피커·블루투스가 잠들었다 깨면서 짧은 음성의 첫 자음이 잘려 가/카/까가 모두 '아'처럼 들리는 문제 → 말하는 동안(+20초) 들리지 않는 신호(−100dB)로 오디오 출력을 깨워 두고, 한글 연구소 자음은 「기역, 가.」처럼 글자 이름 뒤에 음절을 읽음. 근본 해결은 원어민 녹음 또는 유료 TTS로 미리 만든 음성 파일 사용
- 말하는 음절을 노래방처럼 강조, 음절 클릭 시 해당 음절만 천천히 재생, 입모양 가이드 칩
- **2단계 평가**
  1. 즉시 채점: 브라우저 음성 인식(ko-KR) 결과와 목표 문장을 **자모 단위 편집거리**로 비교 → 0–100점, 음절별 정답(초록)/오류(빨강) 표시
  2. AI 코치: 녹음(16kHz WAV)을 Gemini에 전송 → 실제 들린 발음, 점수, 음절별 교정 팁(혀·입 모양)을 JSON으로 수신
- 모든 시도는 서버에 저장 → 교사 대시보드 '학생들이 어려워하는 발음' 집계

### 3.2 Gemini 실시간 대화
- 서버가 API 키를 보관하고 프록시 (키가 브라우저에 노출되지 않음)
- 레슨별 시나리오(상황·목표·목표 어휘·첫 마디)는 교사가 관리자 화면에서 편집
- 구조화 출력(JSON schema): `ko`, `roman`, `en`, `correction{original, corrected, explanation_en}`, `hint_en`, `suggestions_ko[]`
- 시스템 프롬프트: 학생 레벨·모국어 반영, 1–2문장 짧은 해요체, 항상 질문으로 끝내기, **청소년 적합성 가드레일**
- 음성 입력(STT) + 보리 음성 출력(TTS, 입모양 동기화), 로마자/영어 번역 토글
- 대화 기록은 학생·시나리오별로 저장되어 교사가 열람

### 3.3 드라마 스튜디오 (저작권 고려 설계)
실제 방송 영상을 편집·재배포하지 않는 3가지 소스 방식:

| 방식 | 설명 |
|---|---|
| 오디오 드라마 (기본) | 자체 작성 대본 + 캐릭터별 음색(pitch/rate) TTS. 샘플 3편 *전학생 / 편의점에서 / 떡볶이 데이트?* |
| YouTube 임베드 | 방송사 **공식 채널** 영상을 임베드하고 시작·끝 시간으로 대사 구간만 재생 (복제 없음) |
| 영상 파일 | 학교·교사가 직접 만든 영상을 **관리자 화면에서 바로 올리기**(mp4·webm·mov, 끌어다 놓기, 진행률 표시, 최대 500MB) 또는 영상 URL. 서버는 `DATA_DIR/media/`에 스트리밍 저장 후 `/api/media/:id`로 구간 재생(Range), 브라우저 데모는 IndexedDB. 드라마에서 쓰는 영상은 삭제 불가 |

**화면 배치 (영상 보며 대본 학습)**: PC(폭 980px 이상)는 영상·조작 버튼을 왼쪽에 고정하고 대본을 오른쪽 패널 안에서 따로 스크롤, 휴대폰·태블릿은 영상과 한 줄짜리 조작 막대를 상단에 고정하고 대본이 그 아래로 스크롤. 재생 중인 대사로 대본이 자동으로 따라가며(고정 영역에 가리지 않게), ⏮ 이전 대사 / 🔁 다시 듣기 / ⏭ 다음 대사 버튼과 키보드(← → R), 현재 위치(6 / 8) 표시. 「📌 영상 고정」으로 끌 수 있음(브라우저에 기억).

학습 기능: 자막 4단계(한/한+로마자/한+로마자+영/없음 듣기 도전), 대사 클릭 재생·구간 반복, 대사별 쉐도잉(발음 코치), **역할극**(배역 선택 → 상대 대사는 TTS, 내 대사는 음성 인식 채점), 핵심 표현, 퀴즈.
관리자 화면에서 영상을 재생하며 [시작]/[끝] 버튼으로 자막 타이밍을 기록할 수 있습니다.

**자막 파일로 자동 맞추기** (드라마 영상 › 대본·자막 타이밍, `server/subtitles.js`):
- 형식: SRT, WebVTT, CSV/TSV(머리글 한·영 별칭 인식 — 시작/끝/대사/영어/화자 등, 머리글 없으면 시작·끝·한국어·영어 순), JSON(목록, `{lines|cues|segments}`, Whisper `segments`, ms 단위 키, YouTube json3). UTF-8이 아니면 EUC-KR로 읽음
- 한 자막 안의 한국어/영어 줄을 나누고, 「민수: …」, 「[민수] …」, VTT `<v 민수>`를 화자로 인식, 서식 태그 제거
- ① **지금 대본에 타이밍만 맞추기**: 대사와 자막을 문장 유사도(글자 2-gram)로 순서대로 정렬(동적 계획법) — 한 대사가 자막 최대 3개에 걸치거나, 짧은 대사 2개가 자막 1개를 나눠 쓰는 경우(글자 수 비율로 시간 분할), 음악·효과음 같은 여분 자막도 처리. 미리보기에서 일치도 확인 ② **자막으로 대본 새로 만들기** / ③ **뒤에 추가** — 로마자 자동 생성, 새 화자는 등장인물에 추가
- 시간 보정(±초), 연결 안 된 대사의 기존 타이밍 유지 옵션. 적용 후 「저장」을 눌러야 저장됨

### 3.4 관리자(교사) 모드
- **대시보드**: 전체/주간 활동 학생, 레슨별 시작·완료율, 반별 인원, 어려운 발음 Top, AI 연결 상태
- **학생 관리**: 반 필터·검색·정렬, CSV 내보내기, 다중 선택 과제 부여
- **개별 관리**: 프로필·레벨(AI 대화 난이도에 반영)·반 변경, 비공개 교사 메모, PIN 재설정, 레슨별 진도, 발음 기록, AI 대화 로그, 영역별 평가(말하기/듣기/읽기/쓰기/발음/태도 — 학생 공개 여부 선택), 과제(완료 자동 체크), **Gemini AI 학습 리포트**(강점/보완점/다음 단계/학생 메시지)
- **콘텐츠 편집**: 단원 CRUD, 레슨 CRUD·복제·공개/초안 전환, 섹션별 폼 편집기(어휘·문법·대화·발음·퀴즈·문화·AI 시나리오) + JSON 고급 편집, 발음 미리듣기
- **드라마 편집**: 소스 방식, 등장인물 음색, 대본·타이밍, 핵심 표현, 퀴즈
- **녹음 관리** (관리자 › 녹음 관리): 글자·문장별 원어민 녹음. 목록(한글 연구소 자음·모음·비교 세트 / 레슨별 어휘·대화·발음·쓰기 문장 / 저장된 녹음 전체 / 직접 입력)에서 🎤 바로 녹음(24kHz WAV, 앞뒤 무음 자동 제거, 저장 전 미리듣기) 또는 📁 파일(mp3·m4a·wav·ogg·webm, 최대 2MB). 여러 파일 한 번에 올리기는 파일 이름이 곧 문장. 띄어쓰기·문장부호를 무시한 키로 연결되어(「가 카 까」=「가, 카, 까.」) 앱의 모든 음성 재생에서 브라우저 TTS보다 우선 사용, 없으면 TTS. 한글 연구소 자음은 음절(「가」) 녹음을 먼저 찾고 없으면 「기역, 가.」를 TTS로 읽음. 녹음 재생 시 보리 입 모양은 녹음 길이에 맞춰 움직임. 저장: 서버 `DATA_DIR/audio/`(메타데이터는 DB `recordings`), 브라우저 데모는 IndexedDB. API: `GET /audio/index`, `GET /audio/:id`, `POST /admin/audio`, `DELETE /admin/audio/:id`
- **자막·가사 추출** (관리자 › 자막·가사 추출, `server/transcripts.js`, `src/pages/admin/AdminTranscripts.tsx`·`AdminTranscriptEditor.tsx`)
  - **가져오기 4가지**: ① 🎬 동영상 대화·자막 ② 🎵 음악 가사 — 둘 다 YouTube 링크 / 내 파일 / 파일 주소(URL) ③ 📄 기존 자막·가사 파일(SRT·VTT·LRC·SBV·CSV·TSV·JSON·TXT, 시간 없는 TXT는 줄마다 3초, `[Chorus]` 같은 머리줄은 구간으로) ④ ✏️ 빈 문서(들으면서 직접 받아 적기)
  - **AI 추출(Gemini)**: 대화는 말소리를 시간·화자와 함께 받아 적고, 영상에 박힌 자막(화면 자막)은 `onscreen`으로 따로 읽음. 가사는 한 줄씩 시간과 구간(Verse/Chorus…)을 붙임. 동시에 제목·요약·핵심 내용(가사는 주제·주요 표현)을 고른 언어로 정리. 옵션: 말하는 언어(자동 감지), 요약 언어, 화자 구분, 구간(시작·끝 — YouTube·동영상은 Gemini `videoMetadata`로 잘라 보내고, 모델이 구간 기준 시간을 주면 전체 기준으로 보정)
  - **파일 전송**: 14MB 이하는 요청에 바로 넣고, 그보다 크면 Gemini File API로 올림(최대 60MB, 처리 완료까지 대기). 큰 동영상은 브라우저에서 소리만 16kHz 모노 WAV로 뽑아 보냄(화면 자막은 못 읽음, 구간이 있으면 그 부분만 자르고 시간은 서버가 되돌려 맞춤). 원본 미디어는 저장하지 않고 링크·파일 이름만 저장 — 내 파일로 만든 자료를 다시 열면 같은 파일을 열어야 재생됨
  - **편집**: 왼쪽 플레이어(YouTube·영상·음악) + 자막 미리보기(화자·원문·번역·화면 자막), 오른쪽 줄 목록. 재생 중인 줄 강조·자동 스크롤, 줄 번호 누르면 그 위치부터 재생, ⏱ 시작/끝을 지금 재생 위치로, 한 줄 반복, 줄 추가·커서 위치에서 나누기(시간은 글자 수 비율)·다음 줄과 합치기·삭제, 찾기/바꾸기(대사·번역·화자·구간), 전체 시간 ±초 이동, 시간순 정렬, 되돌리기/다시 실행, Ctrl/⌘+S 저장, 저장 안 하고 나가면 경고
  - **번역**: 20개 언어(한국어·영어·몽골어·일본어·중국어 간체/번체·스페인어·프랑스어·독일어·포르투갈어·이탈리아어·러시아어·베트남어·태국어·인도네시아어·튀르키예어·아랍어·힌디어·카자흐어·우즈베크어). 60줄씩 나눠 AI 번역(빈 칸만 / 전체 다시), 언어별로 따로 저장되어 직접 고칠 수 있음. 요약도 다른 언어로 따로 만들 수 있음
  - **보기**: ✏️ 편집 / 📖 정리본(화자·구간별 문단, 번역 병기, 누르면 재생) / 📝 요약·핵심(편집 가능, 지금 대본으로 다시 요약)
  - **내보내기 10가지**: SRT, WebVTT(화자는 `<v>` 태그), YouTube SBV, LRC 가사, TXT, 시간 표시 TXT, Markdown 정리 문서, HTML 정리 문서(Word에서 열기·PDF 인쇄), 엑셀 CSV(BOM, 언어별 번역 열), JSON(다시 불러오면 번역·구간까지 복원). 원문만 / 번역만 / 원문+번역(2개 언어), 화자 이름·화면 자막 포함 여부 선택, 미리보기·복사
  - **저작권**: 상업 음원·방송의 가사·대본은 Gemini가 원문 재현을 막아(RECITATION) 결과가 나오지 않을 수 있음 → 안내 문구로 알리고, 직접 만들었거나 허락받은 자료 사용을 권장. 키가 없으면 예시 결과(자체 작성)로 화면을 시험할 수 있음
  - API: `GET/POST /admin/transcripts`, `GET/PUT/DELETE /admin/transcripts/:id`, `POST /admin/transcribe`(미디어 → 추출·저장, 이 경로만 요청 크기 90MB), `POST /admin/transcripts/translate`, `POST /admin/transcripts/summarize`. DB `transcripts`
- **AI 음성 (Gemini TTS)** (설정 › 발음 음성, 기본값): 음색마다 Gemini 기본 목소리(밝은 여성=Zephyr, 부드러운 여성=Achernar, 아나운서=Erinome, 깔끔한=Despina, 남성=Achird, 부드러운 남성=Algieba, 남성 아나운서=Charon, 어린이=Leda)와 말투 지시문을 연결. 30개 목소리 중 직접 고르기, 모델 이름 설정(기본 `gemini-2.5-flash-preview-tts`). `POST /tts`(로그인 필요, 1인 하루 새로 만들기 400회 제한)가 PCM을 WAV로 바꿔 녹음 저장소에 캐시(최대 3000개) → 같은 문장·목소리는 다시 만들지 않음. 드라마·레슨 대화는 인물마다 다른 목소리 자동 배정(높낮이 기준 남/여/어린이, 한 장면 안에서 겹치지 않게). 순서: 교사 녹음 → AI 음성 → 브라우저 음성(키가 없거나 오류 시). 한두 글자짜리 짧은 소리(한글 연구소)는 「정확히 한 번만 읽기」 지시문을 쓰고, 실패하면 지시문 없이 한 번 더 시도. 한 문장이 실패해도 그 문장만 5분간 브라우저 음성으로 대체(다른 소리는 계속 AI 음성). 설정 화면의 「AI 음성 시험」으로 짧은 소리·문장 생성 결과 확인
- **발음 음성 (TTS 음색)** (설정): 밝은 여성(기본)·부드러운 여성·아나운서·깔끔한·남성·부드러운 남성·남성 아나운서·어린이 8가지 음색 + 높낮이·빠르기 조절 + 특정 음성 고정(선택). 음색 = 기기에 설치된 한국어 음성 중 선호 성별·고품질 음성 선택 + 높낮이·빠르기 (`server/ttsVoices.js`). 남성 음성이 없는 기기에서는 낮은 높낮이로 흉내. 교사 설정은 `settings.tts`에 저장되고 `/status`로 학생 기기에 적용. 드라마 등장인물은 각자의 목소리 설정을 유지, 녹음이 있으면 녹음이 우선
- **설정**: 반 코드, Gemini 모델, 콘텐츠 JSON 백업/가져오기/초기화

### 3.5 학생 화면 언어 선택 (한국어 / English / Монгол)
- 로그인 화면 맨 위와 상단 메뉴에서 언어를 바꿀 수 있고, 선택은 브라우저에 기억됩니다 (처음에는 기기 언어를 따름).
- **화면 문구**: `src/i18n/ui.ts` — 키마다 세 언어를 함께 관리하며, 빠진 키는 타입 검사에서 걸립니다.
- **교재·드라마 설명**: 시드는 영어로 작성하고 `content.mn.json`, `content.ko.json`이 영어 문장 → 번역을 담습니다. 번역이 없으면 영어로 표시되며, 테스트가 공개 콘텐츠의 번역 누락을 검사합니다.
- **AI**: 대화의 해석·교정 설명, 발음 피드백을 선택한 언어로 작성하도록 Gemini에 요청합니다.
- **교사 번역 관리** (관리자 › 번역 관리): 학생에게 보이는 모든 영어 문장과 위치(단원·레슨·영상)를 목록으로 보여 주고, 몽골어·한국어 번역을 고치거나 채웁니다. 교사 번역은 기본 번역보다 우선하며 DB `translations`에 저장되어 학생 화면에 바로 반영됩니다. 「번역 없음」 필터, 위치·검색 필터, 「기본값으로」 되돌리기, Gemini **AI 초안 번역**(한 번에 40문장, 저장 전 검토)을 제공합니다. 콘텐츠 내보내기/가져오기에도 번역이 포함됩니다.
- 교사용 관리자 화면은 한국어로 유지합니다. 몽골어 번역은 원어민 교사의 검수를 권장합니다.

## 4. 시스템 구조

```
[브라우저: React + Vite (TypeScript)]
   ├─ Web Speech API (TTS / 음성인식) · MediaRecorder → WAV
   ├─ YouTube IFrame API
   └─ REST /api  ──►  [Node.js Express 서버]
                         ├─ 인증 (학생: 이름+반코드+PIN(scrypt 해시) / 교사: 관리자 비밀번호), Bearer 토큰
                         ├─ 진도·퀴즈·발음·과제·평가 API
                         ├─ Gemini REST 프록시 (generateContent, JSON schema 출력, 오디오 입력)
                         └─ 저장소: data/db.json (시험판) → 운영 시 PostgreSQL/Firestore로 교체 (server/db.js만 수정)
```

### 데이터 모델 (요약)
`units`, `lessons`, `videos` (콘텐츠) · `students`, `sessions` · `progress{studentId, lessonId, sections, quizBest, completedAt}` · `quizResults` · `pronunciation{target, heard, score, source}` · `chatLogs` · `evaluations{category, score, comment, shared}` · `assignments{lessonId|videoId, due, done}` · `transcripts{title, mode(video|lyrics), source, summary, keyPoints, summaries{언어}, segments[{start, end, speaker, section, text, onscreen, tr{언어}}]}` · `settings{classCodes, geminiModel}`

## 5. 개인정보·안전
- 학생 계정은 이름·반 코드·PIN만 사용 (이메일·생년월일 수집 없음), PIN은 해시 저장
- 음성 녹음은 서버에 저장하지 않음 — AI 피드백 요청 시 Gemini로만 전송되고 텍스트 결과만 저장
- 자막·가사 추출기에 올린 영상·음악도 서버에 저장하지 않음 — Gemini로만 보내고(큰 파일은 Gemini File API, 48시간 뒤 자동 삭제) 받아 적은 글만 저장
- AI 대화는 청소년 적합 가드레일 프롬프트 + Gemini 기본 안전 필터, 모든 대화는 교사가 열람 가능
- 운영 시: HTTPS 필수, 관리자 비밀번호 변경, 학교/보호자 동의 절차, 국가별 아동 개인정보 규정(COPPA/GDPR-K 등) 검토 필요
